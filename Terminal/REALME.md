# 🐧 Shell

Uso **Fish** como mi shell principal debido a su autocompletado inteligente y facilidad de uso. Mi configuración incluye:

* **Prompt:** [Starship](https://starship.rs/) para un indicador visual rápido y personalizable.
* **Gestor de Plugins:** [Fisher](https://github.com/jorgebucaran/fisher) para manejar complementos de forma sencilla.

### 🛠️ Complementos Instalados
* **`jorgebucaran/fisher`**: El corazón del manejo de plugins.
* **`edc/bass`**: Permite ejecutar comandos de Bash directamente en Fish, esencial para scripts de compatibilidad (como el uso de `.bash_profile`).

I use **Fish** as my primary shell for its smart autosuggestions and user-friendly design. My setup includes:

* **Prompt:** [Starship](https://starship.rs/) for a fast, customizable visual indicator.
* **Plugin Manager:** [Fisher](https://github.com/jorgebucaran/fisher) to easily manage add-ons.

### 🛠️ Installed Plugins
* **`jorgebucaran/fisher`**: The core plugin management tool.
* **`edc/bass`**: Enables running Bash commands directly within Fish, essential for compatibility scripts (like loading `.bash_profile`).

---

### 📝 Notas adicionales / Additional Notes
* **LM Studio:** La configuración incluye el PATH para las herramientas de CLI de LM Studio en `/home/mario/.lmstudio/bin`.
* **Kiro Terminal:** Incluye integración nativa para la terminal Kiro detectando la variable `$TERM_PROGRAM`.
* **Syntax Highlighting:** Colores personalizados para comandos (verde), errores (rojo), parámetros (azul) y rutas (naranja) configurados en el `config.fish`.
